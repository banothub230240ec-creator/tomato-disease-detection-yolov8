
# Model Evaluation Results

This folder contains evaluation visualizations generated during
YOLOv8 tomato leaf disease detection model training.

## Results

- Confusion matrix
- F1-score curve
- Precision-confidence curve
- Precision-recall curve
- Recall curve
- Combined training and evaluation graphs

These visualizations help analyze the model's classification
performance and confidence thresholds.
